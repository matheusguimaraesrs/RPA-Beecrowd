## DESCRIÇÃO
O objetivo desse projeto é desenvolver habilidades com Selenium realizando automações de processos e a criação de uma interface mais atraente para o usuário final, conhecida como WPF.

## INSTRUCTIONS
Siga as instruções abaixo para testar a RPA:

### EXECUÇÃO
1. Faça o clone desse repositório: git clone [REPOSITORY LINK]
2. Abra o projeto em seu Visual Studio
3. Execute o programa com CTRL + F5.

### FUNCIONAMENTO
Para que o programa funciona, informe:

1. Seu login do Beecrowd
2. Sua senha do Beecrowd
3. Escolha entre as duas opções (apenas consultar ou consultar e abrir)
4. Clique no botão executar
5. Caso queira encerrar a WPF basta clicar no botão "encerrar"
